Essa atividade_teste_um é um projeto da aula de desenvolvimento de sistemas sobre o basico de como programar backend, nos ensinando como programar em php, mechendo com integração de banco de dados.
Ela serviu para podermos aprender e aplicar na nossa Situação de aprendizagem.
Funcionamento geral do codigo: temos a inicialização com o connect.php, ativando o session.start(), necessário para manter os dados dos usuarios durante a existência dos dados.
Em seguida tem o sistema de login do usuario, que após colocar as informação, verifica no banco pra ver se o usuario existe.
Depois, tem o sistema de cadastro de usuario que pega as informações registradas em um imput e coloca elas no banco de dados.
